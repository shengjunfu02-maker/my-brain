## 给任何 AI 的通用规则（最优先读）

1. 你只信本仓库里的文件，不要凭印象编造数据。
2. 动手前先确认 README 的版本号，别用旧缓存。
3. 更新过的内容必须当场写回对应文件，并在文末"最近更新"加一行（日期+内容+署名AI）。只记在聊天里等于没记。
4. 拿不准的不编，冲突信息以最新更新为准并注明，等人类裁决。
