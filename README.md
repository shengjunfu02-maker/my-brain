# 随身资料 —— AI 入口总说明（先读我）

> 这是一份**自包含的个人工作资料包**。无论你是什么 AI、在什么环境运行，只要用户把这个文件夹给你，你就应该能看懂全部内容并执行里面的工作流。本文件是入口，请先通读本文件，再按任务需要打开对应的工作流文档。

## 一、用户是谁（背景，必读）

- 用户是**通威（水产饲料/动保）业务员**，负责海南文昌片区（锦山镇、抱罗镇、冯坡镇、大致坡等）的养殖户开发与维护。
- 核心工作：走访养殖户 → 测水（pH、氨氮、亚硝酸盐）→ 建立客户档案 → 推动换料/成交 → 定期汇报。
- 行业铁律：**客户抓鱼（出鱼）期间不拜访、不推销饲料**，出鱼后再联系。
- 沟通语言：中文。所有产出（表格、名单、汇报）都用中文。

## 四、通用规则（任何任务都适用）

1. **数据是事实来源**：客户情况、水质读数一律以 `数据/` 里的文件为准；不要凭印象编造客户信息或读数。
2. **路径一律用相对路径**（相对本资料包根目录），不要假设任何绝对路径。本包可能出现在任何机器的任何位置。
3. **改文件前先确认**：更新名单、档案、记录前，把要写入/修改的内容先列给用户确认，再落盘；追加型文件（水质检测记录.csv、拜访记录汇总）只追加、不覆盖历史。
4. **格式保持一致**：每个文件的列结构、命名风格、分类口径都已定型，新增内容严格沿用（详见各工作流文档）。
5. **不确定就问**：塘号归属、客户分类、读数异常等不确定时，先问用户，不要猜。
6. **依赖环境**：水样读数需要 Python + Pillow + numpy + matplotlib；读写 xlsx 需要 pandas + openpyxl。若环境缺库，先安装再执行；无 Python 环境时按 `01_水样测试工作流.md` 的人工读数规则执行。

## 五、业务常识速查（详细版见 `数据/水质检测项目完整档案.txt` 第七节）

- **⚠️ 报警线**：亚硝酸盐 ≥ 0.3（或接近 0.28）标 ⚠️；氨氮 ≥ 5 标 ⚠️。临界塘口是复检回访的天然由头。
- **阴雨天氨氮/亚盐偏高**：光照弱→硝化受抑、径流带氮、底泥上翻、残饵积累。应急：减料停 1–2 餐、增氧机全天开（重点凌晨 4–7 点）、换水 10–20%、沸石粉/黄腐酸钾吸附、亚盐高泼食盐（10–20 kg/亩·米）、过硫酸氢钾改底。
- **销售节奏**：测水/打样是服务入口，服务粘性先于推料；出鱼期静默，放苗期是转料窗口。
