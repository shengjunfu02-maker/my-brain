# 工作流 02：客户名单管理（名单补充 / 档案更新 / 成功率评级）

> 适用场景：用户说“补充名单”“今天拜访了 xxx”“把这条信息加进去”“更新一下档案”等。
> 原则：**改前列出、确认后落盘、只追加不覆盖、口径保持一致。**

## 一、四个数据文件的分工与关系

| 文件 | 角色 | 结构 | 更新时机 |
|---|---|---|---|
| `数据/客户名单.xlsx`（docx 为同内容文字版） | **三级名单总表** | 3 个 sheet：一、通威现有用户 / 二、高意向客户 / 三、潜力培育中；列：人名、情况 | 客户状态变化（转料、意向升降级）时调整分档与情况描述 |
| `数据/用户摸牌表.xlsx` | **客户摸牌主表**（最细） | sheet「客户摸牌表」13 列：序号、客户姓名、客户分类、地址/基地、塘口数、面积（亩）、现用品牌、现有经销商（拿料对象）、负责人、年用量、近期包产、详细情况、跟进建议；另有「分类统计」sheet | 获得新客户/新信息时补充或更新字段 |
| `数据/养殖客户档案.xlsx` | **档案+成功率** | 10 列：序号、人名、拜访日期、现用饲料/品牌、经销商（跟谁拿料）、详细养殖情况、拜访次数、卖料成功率%、成功率等级、成功率依据 | 每次拜访后更新拜访日期、拜访次数、情况、成功率 |
| `数据/养殖客户拜访记录汇总.xlsx` | **拜访流水账** | 3 列：日期（如“10月7日”）、人名、养殖情况 | **每次拜访必追加一行**，只追加不修改历史 |

配套输出物：`数据/客户卖料成功率排名.xlsx` = 档案表按“卖料成功率%”降序重排 + 排名列，用户要排名时从档案重新生成。

## 二、名单补充标准流程（新信息进来时）

用户给的新信息可能是：新客户、拜访纪要、测水结果、成交/丢单、状态变化。按下顺序处理：

1. **查重**：先在摸牌表和档案里按“客户姓名/人名”搜是否已有此人。
   - 已有 → 走“更新”：补字段、追加拜访记录、刷新拜访次数与日期；
   - 没有 → 走“新增”：见第 3 步。
2. **追加拜访流水**：只要发生了拜访/电话沟通，就往 `养殖客户拜访记录汇总.xlsx` 追加一行（日期、人名、养殖情况一段话）。
3. **新增客户**：在摸牌表和档案各加一行。摸牌表尽量补齐 13 字段，不知道的留空、**不要编造**；档案里拜访次数从 1 起，评估成功率（见第三节）。
4. **分类定档**：判断属于哪一级（见第四节），写入摸牌表“客户分类”列；若达到高意向/已成交，同步检查 `客户名单.xlsx` 是否需要加人或换档。
5. **写情况描述的风格**：沿用现有文风——一段话说清“养什么、多大规模、现用什么料、跟谁拿料、什么意向、最近动作”。示例：
   > 陈守建：养殖两口塘约30亩。用百洋，多次为其测水、检藻、推广动保产品。现跟吴建龙拿料，已确认10月起拉通威料，上一茬鱼已抓完，放苗后即转料。
6. **确认落盘**：把要写入的内容列表给用户确认后再写文件；xlsx 用 pandas/openpyxl 读写，保持 sheet 名与列名不变。

## 三、卖料成功率评级口径（档案表专用）

| 等级 | 含义 | 成功率参考区间 |
|---|---|---|
| A 已成交/准成交 | 已拉料或已确认转料 | 70–95 |
| B 明确意向 | 明确表达换料/试用意向 | 40–60 |
| C 有潜力 | 有接触、有服务切入，态度不排斥 | 20–35 |
| D 竞品粘性 | 竞品用得稳、暂无窗口 | 0–10 |
| E 停养/转出 | 停养、转行、塘口转让 | 0（基本放弃） |

“成功率依据”列写主要理由（如“竞品粘性 百洋5602”“已确认10月转料”）。升级/降级要有事实依据，不要因为拜访次数多就自动加分。

## 四、三级客户分类口径（名单/摸牌表通用）

- **一、通威现有用户**：已在用通威料，合作稳定或维护中。动作：日常走访维护、测水服务、持续沟通后续用料。
- **二、高意向客户**：已确认转料时间、或有明确换料意向、或大户在谈。动作：盯转料窗口（放苗期）、政策申请、重点跟进。
- **三、潜力培育中**：用竞品但可接触，靠服务（测水、检藻、动保、补网、光合菌）培育信任。动作：定期服务、找切入时机。

**换档触发条件**（典型）：
- 潜力 → 高意向：客户明确说“下一造换通威”/要了价格政策/试料；
- 高意向 → 现有用户：实际拉了通威料并稳定投喂；
- 任何档 → 注意“停养/转出”信号，及时降级或标注，避免浪费跟进精力。

## 五、业务纪律（名单操作时同步检查）

1. **出鱼期静默**：客户抓鱼期间不拜访、不推销，档案里注明“出鱼中，出完再联系”。
2. **放苗期是转料窗口**：记录里出现“鱼已抓完/准备放苗”是高优先级信号，主动提示用户跟进。
3. **水质临界 = 回访由头**：测水出现 ⚠️ 的塘口，2 天内约复测（衔接工作流 01）。
4. 客户明确反感被追问的（如陶伟静），在档案里注明沟通方式偏好。

## 六、常见指令速查

| 用户说 | 你做 |
|---|---|
| “补充名单：xxx，养了两口塘用百洋……” | 查重 → 摸牌表+档案新增 → 定级定档 → 确认后写入 |
| “今天拜访了 xxx，情况是……” | 追加拜访记录 → 更新档案拜访日期/次数/情况 → 视情况刷新成功率 |
| “xxx 已经拉料了” | 档案成功率升 A、名单换到“现有用户”、摸牌表现用品牌更新 |
| “把成功率排名发我” | 从档案表按成功率降序重新生成排名表 |
